## 🌟 Core Features

This application equips drivers with everything they need to manage deliveries efficiently.

* 🔐 **Driver Onboarding & Auth:**
  * Secure login and password recovery.
  * Dedicated application flow for new drivers to upload required verification documents (National ID, Driving License, and Vehicle Information) for admin approval.

* 📦 **Order Dispatch & Management:**
  * **Home Hub:** A live feed of incoming orders requested by users from the main Flowery app, allowing drivers to quickly accept or reject delivery tasks.
  * **Order History:** A comprehensive log of all completed and cancelled orders with full financial and address details.

* 🗺️ **Live Navigation & Status Tracking:**
  * Integrated Mapbox navigation showing exact routes from the driver to the store, and from the store to the customer.
  * Step-by-step status updates (Accepted, Arrived at Store, Out for Delivery, Arrived at User) that sync instantly with the customer's app.

* 👤 **Profile Control:**
  * Full management of personal details, profile picture, and security credentials.
  * Native Arabic and English localization support via `AppLocalizations`.

## 🧠 Key Engineering Highlights

The tracking module is the core of this application. It is engineered to provide precise real-time location updates while heavily optimizing battery life, API costs, and UI performance.

### 1. Robust Foreground Tracking
The app uses `Geolocator` combined with `ForegroundNotificationConfig` (AndroidSettings) to spawn a persistent foreground service. This ensures the OS does not kill the location stream while the driver is actively delivering. Coordinates are directly streamed to a Firestore `active_orders` document, creating a live data pipeline for the customer app.

### 2. High-Performance Marker Rendering
Rendering heavy map components frequently causes frame drops. This architecture completely decouples the driver, store, and user markers from the Mapbox layer. By mapping physical coordinates to screen pixels (`pixelForCoordinate`) and binding them to a `ValueNotifier<Offset?>`, the markers glide across the screen at a locked 60 FPS using `AnimatedPositioned`, completely bypassing the main widget tree rebuild cycle.

### 3. Service Account FCM Integration
Instead of relying on a middleman server for every tracking ping, the `PushNotificationService` securely signs Firebase requests directly on the client using `googleapis_auth` and an embedded service account JSON. This allows the driver app to instantly fire localized FCM v1 push notifications to the customer the moment an order status changes.

### 4. Smart Routing & Lifecycle Traps
* **Mapbox Throttling:** `GetDirectionsUseCase` is heavily throttled. It only executes a costly API request if the driver's coordinates shift significantly (`_lastCalculatedDriverPos`).
* **Router Guards:** The `GoRouter` redirect logic strictly monitors `SharedPreferences`. If the app crashes or is killed during a delivery, restarting the app will instantly trap the driver back inside the active `trackOrderPath` to prevent order abandonment.

### 5. Centralized Error & Token Handling
Built a robust `AuthInterceptor` using Dio that monitors every outgoing request. If a token expires (401), the interceptor halts execution, triggers a `SessionController.expireSession()` broadcast, and uses the `SessionExpiredHandler` to gracefully prompt the driver to log in again without crashing the active view.

## ⚙️ Tech Stack & Dependencies

* **Core Framework:** Flutter 3.10+ / Dart 3.10+
* **Architecture:** Clean Architecture + Dependency Injection (`get_it`, `injectable`).
* **State Management:** `flutter_bloc` (BLoC / Cubit pattern).
* **Networking:** `dio` with custom interceptors, `retrofit` for type-safe API calls.
* **Maps & Navigation:** `mapbox_maps_flutter` for rendering and directions.
* **Location:** `geolocator` for background/foreground tracking.
* **Firebase:** `cloud_firestore` for live syncing, `firebase_messaging` for push notifications.
* **Local Storage:** `shared_preferences` for session caching.
* **UI & Animation:** `lottie`, `shimmer`, `cached_network_image`.
* **Localization:** `flutter_localizations` (ARB files for En/Ar).
